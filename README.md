# Seowoo Lee — Academic Website

A simple academic website hosted for free with GitHub Pages.

## Publish

1. Create a **public** repository called `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your GitHub username).
2. Upload `index.html` and `style.css` into the repository's root folder (not inside a nested folder).
3. In **Settings → Pages**, choose **Deploy from a branch** and select **main** and **/(root)**, then Save.
4. Visit `https://YOUR-USERNAME.github.io/` when publishing completes.

## Customize

- Change text and section content in `index.html`.
- Change colors, typography, or spacing in `style.css`.
- Replace the photo placeholder with an image when ready.
- The publication and contact sections intentionally contain placeholders.

Never put private information or passwords into a public repository.
